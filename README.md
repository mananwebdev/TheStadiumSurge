# SurgeShield — Modern Multi-page Metro Hacks PS-05

A static HTML/CSS/JavaScript prototype for **The Stadium Surge**.

## Pages
- `index.html` — operations dashboard
- `planner.html` — event configuration form
- `action-plan.html` — generated timeline, checklist and export
- `announcements.html` — English, Hindi and Gujarati announcement builder

## Shared assets
- `css/app.css` — modern responsive design and larger typography
- `js/app.js` — shared demo data, calculations and LocalStorage
- `js/planner.js` — planner interactions
- `js/plan.js` — timeline, checklist and text export
- `js/announcements.js` — multilingual announcements, copy and download

## Run
Extract the ZIP and open `index.html` in a modern browser. No Node.js, MERN, backend, database, or build step is needed. The event settings are saved in browser LocalStorage so they can be used on the other pages in the same browser.

Google Fonts are optional. The app logic itself is local.

## Prototype safety
All estimates use illustrative assumptions. There is no live metro feed, and any real operational decision must be reviewed by authorised metro control staff.
